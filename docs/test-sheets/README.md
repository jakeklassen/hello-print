# Test sheets

Reference sheets for checking that prints come out true to size, centred and not cut off. There is one per named paper size, at 300 dpi. The app makes the same sheets: Settings → Test Sheets, or Print Test Sheet on a Windows preset.

Print borderless at 100% (no "fit to page"), then check:

- **Size:** the centre square measures 50 × 50 mm, outer edge to outer edge. If it's bigger, the printer is enlarging the image (e.g. Epson "Auto Expand").
- **Edges:** the light-blue band shows on every side. Each missing ruler tick is 1 mm cut off on that side.
- **Centring:** the band is the same width on opposite sides.

These PNGs are generated by `src-tauri/src/test_sheet.rs`, and a test fails if they fall out of date. To regenerate them after changing the design:

```sh
cd src-tauri
UPDATE_TEST_SHEETS=1 cargo test test_sheet
```
